## 概要

本講演では、DYNAMIXEL Xシリーズで構成される教育・研究用小型ロボットアーム「MikataArm」向けに、ROS 2 Humbleパッケージ **mikata-arm-ros2** を新規設計・実装し、オープンソースとして公開した取り組みを紹介します。

MikataArmにはROS 2対応パッケージが存在しなかったため、ros2_control / MoveIt2を使用してパッケージを設計・構築しました。シミュレーションと実機をパラメータ一つで切り替えられる構成とし、Dev Containerによるワンクリック環境構築まで含めた、すぐに使える形での公開を目指しています。

- **リポジトリ**: [https://github.com/MikataBots/mikata-arm-ros2](https://github.com/MikataBots/mikata-arm-ros2)
- **ライセンス**: Apache-2.0

## 目的（聴講者の利益）

**自作ロボットアームをROS 2対応させたい開発者**に対して、DYNAMIXEL系アクチュエータを用いて統合するための具体的な設計パターンと実装手順を提示します。

**MoveIt2を初めて使うユーザー**に対して、URDF/xacro作成、SRDF・joint_limits設定、Planning Groupの構成（アーム部 `mikata_arm` とグリッパー部 `hand` の分離）など、MoveIt2セットアップの工程を具体例で解説します。

**再現可能な開発環境を構築したいチーム**に対して、VS Code Dev Containersを活用したロボティクス開発環境のベストプラクティスを紹介します。ROS 2 + MoveIt2 + GUI（RViz）という重い依存関係を、`git clone` → 「Reopen in Container」のワンクリックで再現できる構成により、新メンバーのオンボーディングや教育用途での効果を実例で示します。

## 講演で扱う内容

### 0. パッケージ設計と実装方針

- なるべく省エネ
- 標準的なパッケージを使って再現性の高い環境を作ることを目的にした

### 1. URDFの構築

- URDF Kitchenを用いたURDFの作成
- Onshapeを用いたURDFの作成

### 2. Dev Containerによる開発環境のコンテナ化

- Docker + VS Code Dev ContainersでのROS 2 + MoveIt2 + RViz環境構築
- X11転送によるGUI表示（Linux/Windows/macOS対応）
- GitHub Actions CIとの連携によるビルド検証の自動化
- colcon成果物のDockerボリュームマウントによるビルドキャッシュの永続化

### 2. ros2_controlによるDYNAMIXEL制御

[dynamixel-community/dynamixel_hardware](https://github.com/dynamixel-community/dynamixel_hardware)を用いて、ハードウェアとの接続を実現した

### 3. MoveIt2インテグレーションの実践

- Movit Setup Assistant でSRDF生成からPlanning Groupの構成まで
- グリッパーの `open`/`close` ステートの定義方法
- 小型アーム特有の関節リミット設定と経路計画の注意点

### 4. 安全運用上の知見

- プログラム終了時の脱力によるアーム破損リスクと対策（rest姿勢への遷移必須）
- 実機初回操作時の段階的動作確認手順（グリッパー → rest姿勢 → 小さな動き）

## 議論のポイント

- **教育・研究用小型アームにおいてros2_controlフルスタックは適切か**。軽量なアプローチとのトレードオフはどこにあるか。オーバーエンジニアリングに見えうる選択がもたらす学習効果と再利用性について。
- **Dev Containerアプローチはロボティクス開発の標準になり得るか**。GPU依存やリアルタイム要件のあるプロジェクトへの拡張可能性について。
- **ROS 2対応が進んでいない既存ロボットプラットフォームに対して、コミュニティが新規パッケージを作る際のベストプラクティス**。URDFやハードウェアインターフェースの設計でどこまで汎用性を持たせるべきか。
